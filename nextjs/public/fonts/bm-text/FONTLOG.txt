BM Text
-------

BM Text is a Modified Version of Source Serif 4 4.005 by Adobe, licensed under
the SIL Open Font License 1.1 (OFL.txt in this directory). Source Serif 4 has
the Reserved Font Name "Source", so this subset carries a different name.

Changes from the Original Version:

- Instanced from SourceSerif4Variable-Roman.ttf and -Italic.ttf with the
  optical-size axis pinned at 20. Roman keeps the weight axis from 400 to 600;
  italic is pinned at 400.
- Subset by Unicode range into Latin, Latin Extended, Greek and Cyrillic files,
  keeping the kern, liga, clig, calt, ccmp, locl, mark, mkmk, smcp, c2sc, onum,
  lnum, pnum, tnum, case and sups features. Hinting is removed.
- Family, full, PostScript and instance names are renamed to BM Text / BMText.
  Copyright, trademark and license names are unchanged.

Built by scripts/fonts/build-bm-text.py in the BetterMan repository
(https://github.com/amanthanvi/BetterMan).
