# Reader interactions

## Reach

On a man page, pick flags in the options table (the command composer), focus a SEE ALSO link (the preview), or open a reference table such as ascii(7).

## Spec

`nextjs/e2e/interactions.spec.ts`

## Proves

The command composer on ls(1) builds a command from picked flags and typed values, and can copy it. A cross-reference preview appears on keyboard focus. A reference table can filter rows and sort columns without hiding rows.
