# Command palette

## Reach

On any page with the shell ready, press Ctrl+K or Cmd+K, or use the header Search button.

## Spec

`nextjs/e2e/palette.spec.ts`

## Proves

The combobox named Command palette input opens and takes focus. Choosing tar navigates to that man page. An `@freebsd` prefix opens the FreeBSD variant. A flag query opens the page at that option row.
