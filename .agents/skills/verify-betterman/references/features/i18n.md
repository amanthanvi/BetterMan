# Languages

## Reach

Add `?lang=` to a URL, or use the language links in the footer. The rules live in `docs/i18n.md`. English is the bare URL.

## Spec

`nextjs/e2e/i18n.spec.ts`

`nextjs/e2e/translations.spec.ts`

## Proves

`/man/tar/1` renders English (`html` lang `en`). `/man/tar/1?lang=de` renders German, is `noindex`, and the switch lists all six reviewed languages. A remembered language sends a bare URL to its `?lang=` form with a private redirect.

On the seed, `/man/tar/1?lang=de` is also a translated manual: German manual text with its Debian source line, an English canonical, and a one-line drift note that names the options the translation lacks. `/man/tar/1` has no alternates.
