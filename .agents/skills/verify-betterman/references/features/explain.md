# Explain a command

## Reach

Open `/explain`, or follow Explain this line from a search hit. A shared command is `/explain?cmd=...`.

## Spec

`nextjs/e2e/explain-ui.spec.ts`

`nextjs/e2e/explain.spec.ts`

## Proves

`/explain?cmd=ls%20-lah%20--color` shows the heading Explain a command line, then the reading, then the token grid. Each flag links to its definition. The page is complete without JavaScript. The HTTP API resolves the same seeded command.
