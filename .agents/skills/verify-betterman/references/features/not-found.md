# Not found

## Reach

Open a path no route uses, such as `/definitely/not/a-route`, or a man page that is not in the manual, such as `/man/ta/9`.

## Spec

`nextjs/e2e/not-found.spec.ts`

## Proves

The unknown path is a 404 with the heading No such file or directory, a noindex robots meta, and a Go home link that returns to the search box. A missing man page names the entry and suggests nearby names.
